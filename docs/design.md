# Security Night - Design Note

## 제목
Security Night

## 한 줄 설명
한밤에 정체불명의 괴물을 피해 지하 주차장을 빠져나가야 하는 경비원의 이야기

## 플레이어 목표
괴물의 눈을 피해 발전기를 켜고 카드키를 찾아 정문으로 탈출한다.

## 핵심 행동
- 달리기
- 웅크리기
- 상호작용
- 캐비닛 숨기기

## 적 행동
- 배회
- 플레이어 발견 시 추적

## 승리 조건
발전기를 켜고 카드키를 얻은 뒤 정문으로 탈출

## 패배 조건
괴물에게 잡힘

## 반드시 넣을 기능
- 캐비닛 숨기기
- 스태미나
- 괴물 추적 AI
- 발각도 시스템
- 웅크리기
- 낮은 장애물 통과

## 절대 안 넣을 기능
- 전투 아이템
- 복잡한 퍼즐
- 인벤토리
- 세이브
